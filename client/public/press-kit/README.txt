A Dark Cave press assets
========================

Replace any file in place, keep the same filename, then run:

  npm run press:assets

That refreshes a_dark_cave_press_kit.zip.

Logos: logos/a_dark_cave_logo.png (square), logos/a_dark_cave_logo_round.png (round)
Capsules: capsules/a_dark_cave_header_capsule.jpg (header), capsules/a_dark_cave_small_capsule.jpg (small)
Screenshots must stay named a_dark_cave_screenshot_01.jpg, _02.jpg, ...
GIFs: gifs/a_dark_cave_light_fire.gif
Trailer file: video/a_dark_cave_gameplay_trailer.mp4
YouTube trailer: https://www.youtube.com/watch?v=qDnoID3GcKc
